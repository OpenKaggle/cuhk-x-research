# Release manifest

## Purpose

This release makes the research legible and reusable without treating GitHub
as a warehouse for competition materials. It is intentionally a source and
evidence publication.

## Published

- First-party Large and Small track source, tests, dependency declarations,
  protocols, and shell entry points.
- Participant-authored research records: detailed metrics, evaluation design,
  code and artifact hashes, model identifiers, gate outcomes, and public
  result summaries.
- Links and provenance notes for official data, organizer code, and public
  third-party notebooks.

## Deliberately absent

- Any literal competition input or copied official metadata package.
- Model weights, feature caches, generated submission files, and other binary
  artifacts.
- Record-selection vectors, raw-input-to-output mappings, local paths,
  credentials, and participant contact or identity fields.
- Copied organizer source and third-party notebooks; see
  [UPSTREAMS.md](UPSTREAMS.md).

## Local-deletion gate

Do not delete a local artifact only because this repository exists. A local
item may be deleted only after its permitted backup target, integrity receipt,
and restoration path have been verified. Organizer data should remain under
the organizer's terms rather than being re-uploaded here.
