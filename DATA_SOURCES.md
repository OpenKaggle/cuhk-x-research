# Data sources and acquisition boundary

The CUHK-X competition inputs are not part of this repository.

| Track | Official competition | Official rules |
| --- | --- | --- |
| Large Model | <https://www.kaggle.com/competitions/cuhk-x-competition-large-model-track> | <https://www.kaggle.com/competitions/cuhk-x-competition-large-model-track/rules> |
| Small Model | <https://www.kaggle.com/competitions/cuhk-x-competition-small-model-track> | <https://www.kaggle.com/competitions/cuhk-x-competition-small-model-track/rules> |

The organizer's challenge overview is at
<https://www.ubicomp.org/ubicomp-iswc-2026/cuhk-x-competition/>. It states
that participants retain their code and models while the competition data
remain the organizer's property. Acquire any permitted input directly from the
official source, under the then-current terms, and keep it outside this Git
repository.

This archive intentionally preserves no raw input, copied metadata package,
sample submission, model weight, or local data manifest.
